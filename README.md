# PowerBI-Sales-Dashboard
# 📊 Ecommerce Sales Dashboard (Power BI)

## Overview
This project is an interactive Power BI dashboard that analyzes ecommerce sales data.  
It provides insights into revenue, profit, customer behavior, and product performance.

## Features
- KPIs: Total Sales, Quantity, Profit, Average Order Value (AOV)
- Sales by State and Customer
- Profit trends by Month
- Category and Sub‑Category analysis
- Payment Mode distribution

## How to Use
1. Download the `.pbix` file from this repository.
2. Open it in **Power BI Desktop**.
3. Explore interactive filters and visuals.
